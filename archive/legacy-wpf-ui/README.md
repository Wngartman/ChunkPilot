# Legacy WPF product interface

ChunkPilot used a page-based WPF product interface before the locally bundled React/WebView2 UI
became the only shipped interface. The final active copy was removed from this tree for Alpha 4.
Its complete source remains recoverable from Git history before the `Remove legacy UI and organize
active source` commit.

The native WPF application host, recovery surface, file pickers, and focused native dialogs remain
active. This directory is documentation only and is not compiled or packaged.
