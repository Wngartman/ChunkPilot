# Complete UI design contract
Use calm dark neutral surfaces, restrained purple accent, native Windows typography, FluentIcons.Wpf through `AppIconKind`, semantic tokens, visible focus, truthful state copy, and centralized reduced-motion/high-contrast behavior. No grid texture, emoji icons, raw glyph strings, nested card walls, fake charts, or permanent developer status bars. Wide/Standard/Compact layouts must preserve the same safe actions.
See `docs/UI-DESIGN-SYSTEM.md`, `docs/UI-COMPONENT-CATALOG.md`, and `docs/UI-RESPONSIVE-RULES.md`.
